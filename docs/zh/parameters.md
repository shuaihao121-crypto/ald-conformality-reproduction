当前 A 把 `q` 直接作为输入。`Mfilm/rho/bA/bfilm` 作为论文参数保留在结构体里，但这份核心 RHS 没有利用它们重新计算 q，也没有生成膜厚。B 的 `kB` 常数字段同样保留，但入口通量公式实际使用 R、N_A 与摩尔质量。

容量与位点面积是倒数关系：$s_0=1/q$。换算需在一致单位下进行：

$$
4\ \mathrm{nm^{-2}}=4\times10^{18}\ \mathrm{m^{-2}},
\qquad (4\times10^{18})^{-1}=0.25\times10^{-18}\ \mathrm{m^2}.
$$

摩尔质量是 **kg/mol**，不是 g/mol。论文选择的参数以 TMA–water 氧化铝过程为量级参考，`MA=0.1` 不是实际 TMA 分子量的精确值；这份工程也没有对任何特定设备或实验批次标定。

每个模型共有 41 个条件记录：I–VII 中六组各五点、Case VI 六点，因此 I–VII 是 36 点；再加 Case VIII 五点。历史表以两个模型各 41 点构成 82 行。重复出现的基线属于各自的参数序列，计算 pooled per-condition ratios 时不自动去重。

## 数值参数与物理参数分开理解

| 数值设置 | 当前值/规则 | 出处与边界 |
|---|---|---|
| A 的相对点数 fp | 2 | 论文 Table 2 正式比较值 |
| B 的相对段数 fs | 4 | 论文 Table 2、§4.1 正式比较值 |
| A 起始时间 | 默认 10⁻³ s | 沿用 DReaM-ALD 的非零起点；覆盖率初值仍为零 |
| A 入口饱和判据 | θ≥0.999 | 本地数值筛选，不是论文给定物理常数 |
| B 入口附近饱和判据 | 第一墙段 θ≥0.995 | 本地数值筛选；该段位置为 Δh/2 |
| B ep | 常规 0.05；扫描 β₀=1 用 2，β₀=0.1 用 0.2 | 0.05 来自 Machball 默认；加速值是本地设置，未建立精细步长收敛 |
| B iterative tolerance/maxit | 10⁻⁹ / 500 | 本地 matrix-free BiCGSTAB 设置 |
| dense 切换 | Nseg≤200 | 调试参考范围，超过后不存完整 q |

`ep` 控制隐式更新的相对尺度，是数值步长参数，不能称为反应概率或论文 Table 2 的工艺参数。`fs` 控制段长度与 view-factor 分布，变化时会影响数值覆盖率；正式值 fs=4 并不替代独立的网格收敛验证。

## 分辨率检查的覆盖范围

论文 Table 1 / Fig. 2 使用相对分辨率 0.0625、0.25、1、4、16，并比较 L=500 与 1000 µm。原始 B 分辨率脚本只扫描 0.25、0.5、1 的基线长度；本版本把它归档为部分敏感性检查，不声明完整重画 Fig. 2。主八组扫描使用 fs=4，保留了论文的正式比较设置。

从输入参数到坐标还应核对 $x/H$ 与 $x/L$：Case IV 的 profile 图使用 $x/L$；half-depth 与 broadness 定义仍在 $x/H$ 上计算。改变 H 时，这两个坐标不能互换。
